# Java Practice

This repository contains my Java practice code and exercises as I learn the language.

## Topics and examples

- `Demo/` — introductory demo (`demo.java`)
- `Variables & Datatypes/` — variables and data types (`data.java`)
- `Type conversion/` — type conversion examples (`type.java`, `sec.java`)
- `Conditional/` — conditional statements (`one.java`)
- `Operators/` — arithmetic, bitwise, logical, and relational operators
  (`arithmetic.java`, `bitwise.java`, `logical.java`, `relational.java`)
- `iteration/` — loops (`loop.java`)
- `arrey/` — array examples, including two-dimensional arrays (`one.java`, `two_d.java`)
- `Stack/` — stack example (`demo.java`)
- `linked/` — linked-list example (`LL.java`)
- `queue/` — queue examples (`demo.java`, `demo_2.java`)

## How to run an example

1. Open a terminal in the folder containing the `.java` file.
2. Compile the file:
   ```bash
   javac FileName.java
   ```
3. Run it using the class name declared in the file:
   ```bash
   java ClassName
   ```
