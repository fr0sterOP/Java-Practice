# Java Practice

This repository contains my Java practice code and exercises as I learn the language.

## Folder Structure

* `1st/` - Basic setup and introductory Java programs (`demo.java`)
* `Variables & Datatypes/` - Practice programs covering variables and data types (`data.java`)

## How to Run

1. Open a terminal in the folder containing the `.java` file.
2. Compile the file:
   ```bash
   javac FileName.java
   ```
3. Run the compiled program:
   ```bash
   java FileName
   ```
